# muse

Muse 的工作仓库：存放为用户构建的代码、文档、工具与项目产出。

## 本地工作区

- 固定本地工作区为 `~/workspace/`，所有工作文件先落在这里。
- 入库时按项目建子目录（如 `lpprocess/`、`youtube/`），提交前确认路径映射正确，不把工作区根目录的杂项推进来。

## 公开仓库安全规则

本仓库是**公开**的，任何人可见。提交代码前必须遵守：

1. **不提交密钥**：SSH 私钥、API 私钥、证书（`*.pem`、`*.key`、`*.p12`、`id_rsa*` 等）一律不进仓库。
2. **不提交令牌**：API token、access token、refresh token、密码、验证码不进仓库，不出现在代码、文档和提交信息里。
3. **不提交 VPN 配置**：OpenVPN（`.ovpn`）、WireGuard 等客户端配置文件不进仓库。
4. **不提交环境变量文件**：`.env`、`*.env` 不进仓库；需要示例时用 `.env.example`，只写字段名不写真实值。
5. **敏感信息走安全通道**：密码、验证码、令牌通过安全方式单独传递，不落盘到工作区。
6. **提交前检查**：`git status` / `git diff` 过一遍，确认没有敏感文件；`.gitignore` 已覆盖常见敏感文件类型。
7. **误提交处理**：一旦误推了密钥，立刻作废并更换该密钥——只删文件不够，git 历史里还能找回。

## 目录约定

- `docs/`：说明文档、设计记录
- `tools/`：可复用的脚本与工具
- `projects/<项目名>/`：各项目产出
